# StackMate

> Your Spring Boot application explains its own failures. Locally.

StackMate is an offline-first diagnostics layer for Spring Boot 4.1 and Java 21. The deterministic diagnostics
engine is the product core; optional local JVM inference may explain only validated, sanitized facts.

The project is under active implementation. See [the live progress log](docs/progress.md) and
[the implementation plan](docs/implementation-plan.md). Unsupported performance or production-readiness claims
are intentionally omitted.
