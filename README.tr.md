# StackMate

> Spring Boot uygulamanız kendi hatalarını yerel olarak açıklar.

StackMate, Spring Boot 4.1 ve Java 21 için çevrimdışı öncelikli bir tanılama katmanıdır. Ürünün temeli
deterministik tanılama motorudur; isteğe bağlı yerel JVM inference yalnızca doğrulanmış ve temizlenmiş olguları
açıklayabilir.

Projenin uygulaması devam etmektedir. Güncel durum için [ilerleme kaydına](docs/progress.md), yürütme sırası için
[uygulama planına](docs/implementation-plan.md) bakın. Doğrulanmamış performans veya üretim-hazırlık iddiaları
özellikle kullanılmamıştır.
