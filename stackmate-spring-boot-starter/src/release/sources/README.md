# StackMate starter sources

`stackmate-spring-boot-starter` is intentionally a dependency-only Maven starter and contains no Java source of its
own. Its implementation is provided by the separately published `stackmate-core` and
`stackmate-spring-boot-autoconfigure` artifacts, each with its own sources JAR.

Project documentation and source code are available at https://github.com/kalayciburak/stackmate.
